# Live runs

A built feature that has never been run against a real Domino is a claim, not a fact. #25 exists
because #14 and #15 shipped on unit tests and a careful read of the SDK — honest, and not the same
thing — and the run that followed found a criterion that needed rewording and a statement form that
had never actually been executed.

One file per session, named by date. Record what was run, what was seen, and what was *not* — an
unrun step recorded as unrun is worth more than a tick.
